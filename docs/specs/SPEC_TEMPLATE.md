# Spec 模板

## 标题

一句话说明要解决什么问题。

## 背景

- 当前现状
- 为什么现在要做
- 已知约束或依赖

## 目标

- 明确要达成的结果

## 非目标

- 明确这次不做什么，避免范围漂移

## 用户流 / 角色

- 用户是谁
- 关键路径是什么
- 成功与失败分别如何呈现

## 状态与数据契约

- 输入数据
- 派生状态
- 持久化状态
- 兼容旧数据策略

## API / Schema / 表单约束

- 相关接口
- 字段含义
- 条件显隐 / 互斥 / 默认值
- 失败模式与错误文案

## 实现边界

- 前端负责什么
- 后端负责什么
- 哪些逻辑必须由 schema / capabilities / adapter 承担

## 可观测性

- 日志
- 开发者模式
- 追踪字段

## 验收标准

- 自动化验证
- 手工验证
- 回归关注点

## 文档更新

- 需要同步更新哪些文档
