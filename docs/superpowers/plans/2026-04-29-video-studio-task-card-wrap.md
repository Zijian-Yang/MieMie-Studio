# 视频工作室任务卡片标签换行修复

## 背景

HappyHorse 任务卡片同时展示“参考生视频”、`HAPPYHORSE`、状态标签和完成进度。卡片宽度不足时，原布局使用单行 `flex + space-between`，标签组不换行，导致“已完成”和右侧 `1/1` 被挤出卡片。

## 计划

1. 定位任务卡片元信息行布局。
2. 增加最小回归脚本，约束任务卡片标签区必须可换行、进度必须可单独保留宽度。
3. 将任务卡片布局样式抽出为可测试常量，并在 `VideoStudioPage` 复用。
4. 更新 changelog，运行前端布局脚本、typecheck 和 diff 检查。

## 验收

- 长 provider 标签不会把状态和进度挤出卡片。
- 标签区允许多行换行显示。
- `1/1` 进度在空间不足时可移动到下一行并保持右侧对齐。
